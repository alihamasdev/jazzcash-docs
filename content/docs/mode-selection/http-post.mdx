---
title: HTTP POST (Page Redirection)
description: Integrate JazzCash hosted checkout and payment page redirection via standard HTTP POST.
---

For an HTTP Post mode of integration, merchant can choose from Custom Development or Plugins while developing his e-commerce website.

## Custom Development

The merchant may choose to develop a customized website using online resources including different platforms available over the World Wide Web. The following criteria has to be followed in order to further proceed with the integration.

The merchant would then be required to select a transaction type from the below mentioned list:

1. Card Payment
2. Mobile Account
3. Voucher Payment

- After selecting the preferred transaction type, a list of codes become available for the merchant to copy (a `copy` button is also visible on the bottom left).
