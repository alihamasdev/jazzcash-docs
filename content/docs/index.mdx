## About Me & The Story Behind This Project

Hi, I'm **Ali Hamas** ([@alihamasdev](https://github.com/alihamasdev)), a full-stack software engineer who regularly builds web applications and e-commerce platforms using **Next.js**, **React**, **Node.js**, and **Express**.

While developing an e-commerce website for a client, I needed to integrate the JazzCash payment gateway to accept local payments in Pakistan (including Mobile Wallets, Credit/Debit Cards, and Vouchers). When I searched for developer tooling, I ran into a major obstacle: **there was no modern, maintained, type-safe Node.js SDK for JazzCash**.

Integrating the gateway manually meant calculating HMAC-SHA256 integrity hashes, sorting request fields, handling multi-step redirect forms, and parsing server-to-server webhook callbacks from scratch without type definitions or modern runtime helpers.

To solve this for myself and the wider developer community, I created and open-sourced **`rawapay`**:

- **GitHub Repository**: [github.com/alihamasdev/rawapay](https://github.com/alihamasdev/rawapay)
- **npm Package**: [`rawapay`](https://www.npmjs.com/package/rawapay)

`rawapay` provides a developer-friendly, zero-friction Node.js and TypeScript library for initiating payments, computing secure hashes, tokenizing cards, and handling webhook responses across Next.js API routes, Express servers, and serverless environments.

## Why Rebuild the JazzCash Documentation?

While building `rawapay`, I spent countless hours consulting the official [JazzCash Sandbox Documentation v4.2](https://sandbox.jazzcash.com.pk/SandboxDocumentation/v4.2/index.html). While the underlying gateway specifications are functional, the documentation experience felt stuck in the past:

- **Legacy HTML Structure**: Nested frames, non-responsive tables, and static layouts make navigation clunky on modern monitors and mobile devices.
- **No Markdown or Developer Experience**: No copy-to-clipboard code blocks, dark mode, or fast client-side fuzzy search.
- **Not AI-Ready**: Today's developers build alongside AI pair programmers and agentic coding workflows (such as Cursor, Windsurf, Claude Desktop, Antigravity, and GitHub Copilot). Legacy HTML documentation cannot be cleanly digested or referenced by Large Language Models (LLMs) without significant noise and truncation.

I decided to recreate the complete JazzCash v4.2 documentation from the ground up as a modern, high-performance, developer-first platform.
