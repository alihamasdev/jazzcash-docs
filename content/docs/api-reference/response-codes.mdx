## Tokenization Response Codes

The JazzCash payment gateway provides a simulated system to perform integration testing for tokenization operation and tokenized payments. During the integration, you will receive various response codes from JazzCash in respective field of tokenization response to indicating the result of request processing. To facilitate your integration, below is the list of all response codes expected from JazzCash payment gateway.

| Code  | Description                                                                                                  |
| :---- | :----------------------------------------------------------------------------------------------------------- |
| `T00` | The tokenization operation was successfully processed                                                        |
| `T01` | The card tokenization request has been accepted.You will be shortly notified on your system about its status |
| `T48` | Tokenized Card Number Provided is Expired                                                                    |
| `T49` | Tokenized Card Number Provided is Invalid                                                                    |
| `T59` | The delete token operation resulted in an internal error and hence cannot be processed                       |
| `T69` | The update token operation resulted in an internal error and hence cannot be processed                       |
| `T79` | The retrieve token operation resulted in an internal failure and hence cannot be processed                   |
| `T88` | Request validation failed                                                                                    |
| `T89` | The create token operation resulted in an internal error and hence cannot be processed                       |
| `T96` | Current operation is not allowed for non-registered customer or Merchant is not configured with tokenization |
| `T97` | The tokenization operation resulted in an external error and hence cannot be processed                       |
| `T98` | The tokenization operation resulted in an internal error and hence cannot be processed                       |
| `T99` | The tokenization operation was declined or rejected by the gateway, acquirer or issuer                       |
